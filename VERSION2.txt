
Data Validation & Cleaning

1. Duplicate Record Detector. Flag or merge rows that share the same SSN or identical OWNER + DOB combinations before exporting.
2. Invalid Field Highlighting. Highlight cells in red or yellow when dates (DOB/DOD) are malformed, DOD occurs before DOB, or SSN digits are missing.
3. Auto-Formatting & Text Normalization. Automatically trim extra spaces, standardize casing (Title Case for names and addresses), and format SSNs consistently (XXX-XX-XXXX).
4. SSN Masking Toggle. Add a one-click privacy switch to mask SSNs (***-**-1234) in the preview table and exported reports when sharing files externally.
5. Error & Skipped Line Log. Display a downloadable summary report showing exact line numbers from the .txt file that failed to parse or contained corrupt data.

Table Search, Filtering & Editing

6. Instant Global Search Bar. Filter hundreds or thousands of parsed records in real time by name, SSN, city, or street address.
7. Multi-Column Filtering. Add dropdown filters for CITY, RESCODE, SEX, and AGE ranges (e.g., age 65+ or specific date-of-death months).
8. Inline Cell Editing. Allow users to double-click any cell in the preview table to fix typos directly before exporting to Excel or CSV.
9. Row Deletion & Manual Row Entry. Let users remove unwanted records or manually insert a missing vital record directly inside the UI.
10. Sortable Columns & Pagination. Add ascending/descending column sorting and pagination (e.g., 25, 50, or 100 rows per page) so large .txt files stay fast and responsive.

File Input & Batch Processing

11. Multi-File Batch Upload. Allow dropping multiple .txt files at once and merging them into a single combined report with source-filename tracking.
12. Custom File Delimiter & Layout Profiles. Support fixed-width text files alongside comma, tab, or pipe-delimited .txt and .csv inputs.
13. Line-Ending Auto-Detection. Support both Windows (\r\n) and Unix/macOS (\n) line breaks automatically so files from any system parse cleanly.
14. Recent Files History. Store a list of the last 5–10 processed files on the home screen for quick one-click reloading.

Export & Reporting Enhancements

15. Formatted PDF Report Export. Generate print-ready PDF summaries with a report header, generation timestamp, total record count, and page numbers.
16. Custom Column Selector. Let users check or uncheck which columns (SSN, RESCODE, AGE, etc.) are included in the final .xlsx or .csv export.
17. Export Filtered Results Only. Give users the option to export either all loaded records or only the rows currently matching their active search/filter.
18. Styled Excel Workbooks. Upgrade the .xlsx export with bold header rows, frozen top panes, auto-adjusted column widths, and formatted date cells.
19. Custom Output Filename & Folder Picker. Use Electron's native save dialog (dialog.showSaveDialog) so users can pick their destination folder and customize the filename before saving.

Analytics, Security & Desktop Experience

20. Summary Statistics Dashboard. Show quick cards at the top of the report with total records, breakdown by RESCODE or CITY, gender counts, and average age.
21. Audit Trail & Activity Log. Maintain a local history log recording when each file was imported, how many records were processed, and when exports occurred.
22. Dark Mode & High-Contrast Theme. Add a theme toggle in the navbar for comfortable viewing during extended data-entry sessions.
23. Keyboard Shortcuts & Native Application Menu. Add desktop shortcuts (Ctrl+O to open a .txt file, Ctrl+S to export Excel, Ctrl+F to jump to search).
24. Offline Local Storage / Draft Auto-Save. Automatically save in-progress edits locally using IndexedDB or local JSON storage so work is never lost if the window closes accidentally.
